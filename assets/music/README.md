# Music for Shorts Studio

Put background tracks here (`.mp3`, `.m4a` or `.wav`). Shorts Studio picks one at random, preferring
files whose name contains the author's `music_mood` from their voice file (for example
`quiet-piano_01.mp3` for Ren Hawthorne, `soft-ambient_01.mp3` for Hanako journals).

**Only add tracks you hold a licence to use in commercial social posts.** Uncleared music can get
videos muted or claimed on TikTok, Instagram and YouTube. If this folder has no tracks, shorts render
with voice only.
